# S-IT-SmartPack

🇩🇪 [Diese Seite auf Deutsch](README_DE.md)

Pack, extract and securely delete folders – free Windows tool by Sattler IT-Service.

- Folders as an ISO file that mounts as a drive in Explorer with a double-click – even several folders from different drives in one file
- 7z and ZIP archives with maximum compression, optionally with a password
- Ten speed dial buttons: fixed tasks with one click, every run with date and time in the file name
- Extract archives and ISO files, via speed dial also back to the original location
- Verify result, skip locked and unreadable files, secure delete
- Deutsch, English, Nederlands

## Download

Download `sit-smartpack.zip` from [Releases](https://github.com/SattlerIT/sit-smartpack/releases), extract it and run `S-IT-SP-Start.exe`. No installation, no administrator rights required.

The ISO function needs the Microsoft file `oscdimg.exe`. It is not included in the package; the help in the program explains how to get it.
